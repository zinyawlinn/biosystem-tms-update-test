# Biosystem TMS — Update Test Repository

This public repository is used **only for internal testing** of the Biosystem TMS desktop application's online software-update process.

Test releases may contain installer binaries, update manifests, and digital signatures required to verify updates.

**Not for customer distribution.** Test builds are not approved production releases.

No application source code, customer databases, credentials, private signing keys, or confidential files should be uploaded here.
